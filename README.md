# three_tasks
    3つのタスクを管理するアプリ。管理するタスクは、「日単位」、「週単位」、「月単位」、「年単位」がある。
    タスクにはレジュメ機能があり、進捗や改善点などの詳細を記載できる。
    タスクは履歴（カレンダー形式）からも参照できる。
